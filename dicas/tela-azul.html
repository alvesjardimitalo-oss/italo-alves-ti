Tela azul (BSOD): o que significa e o que fazer

O que é a tela azul do Windows, o que o código de erro indica e quando é problema de programa ou de peça.

A famosa tela azul (BSOD, Blue Screen of Death) aparece quando o Windows encontra um erro grave e precisa parar para não corromper os seus dados. Ela traz uma mensagem e um código de parada, como MEMORY_MANAGEMENT, CRITICAL_PROCESS_DIED ou IRQL_NOT_LESS_OR_EQUAL.

Dica de ouro: tire uma foto da tela azul. O código e, às vezes, o nome do arquivo mostrado ajudam muito a encontrar a causa.

Causas mais comuns

  • Driver com problema: logo após instalar um driver, uma atualização ou um periférico novo.
  • Memória RAM com defeito: telas azuis aleatórias, com códigos diferentes a cada vez.
  • Disco com setores defeituosos: lentidão, arquivos corrompidos e erros ao iniciar.
  • Superaquecimento: o erro aparece quando o computador está sob carga.
  • Atualização do Windows interrompida ou arquivos do sistema corrompidos.

O que você pode tentar

  • Se começou após instalar algo, desinstale ou use a Restauração do Sistema.
  • Rode o Windows Update até o fim.
  • Faça backup dos arquivos importantes o quanto antes. Se o problema for o disco, ele pode piorar. Veja como.

Quando procurar o técnico

Se a tela azul se repete, aparece logo ao ligar ou vem acompanhada de lentidão extrema, é hora do diagnóstico. Testes de memória e de disco mostram se o problema é de programa ou de peça.
