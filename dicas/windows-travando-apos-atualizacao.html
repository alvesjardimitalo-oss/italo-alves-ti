Windows 11 travando ou lento depois de uma atualização: o que fazer

Como desfazer uma atualização problemática, reparar arquivos do sistema e quando a lentidão é sinal de disco no limite.

Às vezes uma atualização do Windows chega com problema ou não termina de instalar direito. Os sintomas são travamentos, tela preta, programas fechando ou lentidão logo depois de reiniciar.

1. Deixe terminar

Depois de uma atualização grande, o Windows continua trabalhando em segundo plano por um tempo (indexação, otimizações). Deixe o computador ligado e conectado por 30 a 60 minutos antes de concluir que há problema.

2. Desinstale a atualização

Em Configurações › Windows Update › Histórico de atualizações › Desinstalar atualizações, remova a mais recente e reinicie. Se o Windows nem inicia, ele costuma abrir sozinho o Reparo automático, onde há a opção de desinstalar a última atualização.

3. Repare os arquivos do sistema

Abra o Terminal (Administrador) e rode, um de cada vez:

  • DISM /Online /Cleanup-Image /RestoreHealth
  • sfc /scannow

Eles comparam os arquivos do Windows com as cópias originais e corrigem o que estiver danificado.

4. Drivers

Se o problema é tela, som ou Wi-Fi, o vilão costuma ser o driver. Instale a versão do site do fabricante do notebook (Dell, Lenovo, Acer etc.).

Lentidão que nunca melhora? Atualizações recentes do Windows 11 pesam bastante em HD mecânico. Se o seu computador ainda usa HD, a troca por SSD resolve de vez. Entenda.
